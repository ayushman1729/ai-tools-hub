# ⚡ AI Tools Hub

A minimalist, high-performance suite of free AI-powered writing and productivity utilities. Built with **Next.js 16 (App Router)**, **TypeScript**, and **Tailwind CSS**.

🌐 **Live Demo:** [https://ai-tools-hub-ten-nu.vercel.app](https://ai-tools-hub-ten-nu.vercel.app)

---

## ✨ Features

- ✍️ **AI Text Rewriter & Paraphraser**: Rephrase sentences, essays, or code explanations with customizable tones (Professional, Formal, Casual, Academic, Creative) and multi-language support (English, Hindi, Spanish, French, German).
- 📝 **AI Paragraph Generator**: Construct structured, coherent paragraphs on any subject with fine-grained word count targets and paragraph quantity controls.
- #️⃣ **AI Hashtag Generator**: Generate high-converting, viral hashtags for Instagram, Twitter/X, TikTok, and LinkedIn with one-click individual chip copying and bulk copy.
- 📧 **AI Email Writer**: Draft articulate business correspondence, job follow-ups, and cold outreach with automated subject lines and polished formatting.
- 💎 **100% Free Forever**: Zero subscriptions, no login walls, no credit cards, and no daily throttling.
- 🔒 **Zero Data Retention**: Strict privacy-first design — prompts and texts are processed in-memory and never stored.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **AI Engine:** Google Gemini API (`gemini-3.8-flash` / `gemini-1.5-flash`) + Smart Semantic NLP Fallback Engine
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/ayushman1729/ai-tools-hub.git
cd ai-tools-hub
```

### 2. Install dependencies
```bash
npm install
```

### 3. (Optional) Set up Gemini API Key
Create a `.env.local` file in the root directory:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
*(Get a free API key at [Google AI Studio](https://aistudio.google.com/app/apikey))*

### 4. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
